Часовая, минутная и секундная стрелка показывают время, снизу отображается запись в числовом формате.

1. На старте или по кнопке "Москва GMT + 3" по api запросу часы получают точное московское время. Раз в час происходит повторный запрос на сервер.
2. По кнопке "Ввести вручную" появляется возможность ввести время в формате часы, минуты, секунды.
     - При нажатии "ОК" часы продолжают ход с установленного времени.
     - Так как в момент ввода времени часы не останавливают ход, при нажатии "Передумал" не происходит никаких изменений.
3. По кнопке "Настроить вручную" часы останавливают ход и появляется возможность удерживая и перетаскивая часовую стрелку настраивать время с учетом 24 часовой системы.

Запустить и проверить можно на итчике:
https://paarturnax.itch.io/clock1tz?secret=7CFalAYKP0PsjSJPJDAa8c8Su8Y

Проект на задумывался для запуска с мобильных устройств: запуск и часть функционала доступны, но интерфейс слабо адаптирован и нет возможности ввести время с клавиатуры.
